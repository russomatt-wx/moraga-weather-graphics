How the test works

10-day forecast learning: each model's day-ahead high and low are compared with what was observed, and a bias correction is kept only where testing on earlier days shows it helps. The NOAA track repeats this using NOAA's quality-controlled URMA analysis (hourly, 2.5 km) at each location instead of the station, so the corrections could be used in a paid app. Both are then scored against the station. NOAA's daily high and low come from hourly values, so they run slightly milder than a station's 5-minute extremes.

Every hour the job reads NOAA's newest Real-Time Mesoscale Analysis at each station's location and logs it next to the station's reading. The corrected estimate subtracts the average error that location showed in the same situation (day or night, calm or breezy) over the previous 14 days, using only earlier hours, so the score is a fair test of how it would perform live.

The NOAA estimate is public-domain data. The station readings are used here only to measure and train it.
